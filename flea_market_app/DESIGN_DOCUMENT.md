# フリマ商品管理アプリ 設計書

## 概要
メルカリ・ラクマなどのフリマサイトで売る商品を管理し、プラットフォーム間の価格比較ができるFlutterアプリ。

## 主な機能

### 1. 商品管理 (CRUD)
- 商品の追加・編集・削除
- 商品名、説明、カテゴリ、状態（ランク）、仕入れ価格を管理
- 複数写真の登録（カメラ・ギャラリーから）
- タグ付けによる整理
- メモ機能

### 2. 価格比較
- メルカリとラクマの価格を並べて入力・表示
- 最高値のプラットフォームをハイライト表示
- 価格差の表示
- 各プラットフォームの出品URLを保存してワンタップでアクセス

### 3. 利益計算
- 仕入れ価格から利益額・利益率を自動計算
- 商品一覧でリアルタイムに利益表示
- 編集画面でプレビュー表示

### 4. ステータス管理
- 下書き → 出品中 → 売却済み / 取り消し のフロー
- ステータス別フィルタリング

### 5. 統計・分析画面
- 総商品数・出品中・売却済み件数のサマリー
- 売上・仕入・利益の合計
- カテゴリ別商品数の円グラフ
- メルカリ/ラクマ別出品数・平均価格
- 利益上位5商品ランキング

### 6. 検索・フィルタ
- 商品名・説明・タグでテキスト検索
- ステータス別フィルタ
- カテゴリ別フィルタ

## アーキテクチャ

```
lib/
├── main.dart              # エントリーポイント
├── models/
│   └── product.dart       # Productモデル（PlatformPrice含む）
├── providers/
│   └── product_provider.dart  # Riverpodプロバイダー
├── screens/
│   ├── home_screen.dart       # 商品一覧（メイン）
│   ├── product_detail_screen.dart  # 商品詳細
│   ├── product_form_screen.dart    # 追加・編集フォーム
│   └── stats_screen.dart      # 統計・分析
├── services/
│   └── database_service.dart  # SQLiteデータベース
├── utils/
│   ├── formatters.dart    # 通貨・日付フォーマッター
│   └── theme.dart         # テーマ・カラー定義
└── widgets/
    └── product_card.dart  # 商品カードウィジェット
```

## 商品状態ランク
- S: 新品・未使用
- A+: 未使用に近い
- A: 目立った傷や汚れなし
- B: やや傷や汚れあり
- C: 傷や汚れあり
- D: 全体的に状態が悪い
